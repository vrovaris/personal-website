# vrovaris.com

Personal site. Work in progress — nothing is live yet.

Built with Astro, plain CSS, and a small number of React islands, deployed on
Cloudflare Pages. Two interactive pieces are planned: a seccomp policy playground
built on real traces, and a shell grammar parser compiled from C to WebAssembly.

    docs/DECISIONS.md       append-only decision log
    docs/practices/         engineering standards for this repo
    AGENTS.md               how to work here
