My personal site, designed as an open notebook. Ruled pages, index tabs, pen doodles that draw themselves, and photos you can drag around. Built with Astro, TypeScript, and plain CSS.

Run it locally if you'd like:
```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # static site in dist/
```
